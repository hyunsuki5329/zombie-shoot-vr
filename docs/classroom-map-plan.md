# P09 실제 강의실 → 폐교 맵

사용자 제공 크기: 약6.3×14m. 스캔 배치도의 긴 X방향14m, 짧은 Z방향6.3m로 정규화한다. 정밀 실측으로 표현하지 않는다. 높이3m는 추정이다. 사용자가 없는 부분으로 지정한 세 돌출부는 포함하지 않는다.

- ClassroomStructure.asset: 고정 classroom/AbandonedSchool, 사용자 크기와 ScanEstimated 가구 요소, 독립 앵커. 스캔의 -8도 회전 배치도에서 A교탁, B~F학생 가구 구역을 사용한다. 개별 학생 책상/의자 수는 이미지에서 확정하기 어려워 구역마다4조(총20조)로 추정한 검토용 배치다. 사용자 확인 시 수정한다.
- ClassroomSetup.cs: 새 씬으로 생성하고 기존 Room을 수정하지 않는다. 벽/바닥/천장은 구조 박스, 책상/의자는 추출 메시와 일치하는 MeshCollider로 생성한다. 바닥은 URP 원본 바닥 재질, 벽은 원본 벽 프리팹을 구조 크기에 맞춘다. 가구는 원본 비율을 보존한다.
- ClassroomMapTests: 14×6.3m 구조, 실제 경로에 연결된 모든 앵커, 외부 원본 FBX/개인 스캔 의존성 없음, 가구 메시 충돌을 검사한다. 씬 없는 상태 실패부터 확인한다.
- 격리 프로젝트 생성·NavMesh·렌더·자동 검증 후 실제 프로젝트에 반영한다. 이후 Room+Classroom 빌드와 두 맵 전환 회귀·복원 manifest·실기 인수까지 진행한다. 첫 생성만으로 P09 완료라고 하지 않는다.

출입구 위치와 창문/천장 세부는 스캔 누락 때문에 확정되지 않았다. 첫 검토용 씬은 내부 전투 공간을 구성하며 외부 복도/문은 실제 위치 확인 후 추가한다. 실기 검증 시 가구 배치·시야·동선·밝기를 우선 확인한다.
