# P08 메뉴·HUD 실기 확인

대상: `Zombie Shoot VR/Builds/Windows/MenuLab/WaveLab.exe` (빌드 성공 및 해시는 p08-menu-view.json 참고).

1. Quest Pro + Virtual Desktop에서 실행한다. 시험장 점수는 저장하지 않는 연습 환경이다.
2. 준비 8초 후 적이 생성되는지, 오른팔에 HP·실제 웨이브·처치 수가 읽히는지 확인한다.
3. X로 정지한다. 메뉴가 현재 바라보던 방향 앞에 나타나고, 머리·손 추적은 유지되며 적·투사체·이동은 멈추는지 확인한다.
4. 오른손 포인터로 Resume을 선택한다. 트리거를 계속 누르고 왼손 앞부분을 잡아도 곧바로 발사되지 않고, 트리거를 놓았다 다시 누르면 발사되는지 확인한다.
5. Retry 버튼으로 HP100·탄창30·처치0·도달0·준비8초로 돌아가는지 확인한다.
6. HP25 이하에 오른팔의 붉은 글씨와 느낌표가 보이는지, 사망 후 결과의 실제 웨이브·처치 수가 일치하는지 확인한다.
7. 팔 UI와 메뉴를 두 눈으로 읽고, 조준·탄창 삽입·왼손 잡기를 가리는지 기록한다. 버튼 포인터와 클릭 인식 여부를 특히 확인한다.

이번 빌드의 Settings와 Maps unavailable 버튼은 비활성이다. 실제 스캔 맵 선택·설정 조절·실제 맵의 영구 기록 통합은 후속 작업이다. 디스크 기록·저장 실패 재시도는 자동 시험으로 검증했지만 이 시험장은 실제 방/강의실 기록을 만들지 않는다.

결과는 날짜, VD 설정, 성공한 단계, 실패/가림 위치와 함께 기록한다. 자동 시험 통과를 실기 완료로 취급하지 않는다.
