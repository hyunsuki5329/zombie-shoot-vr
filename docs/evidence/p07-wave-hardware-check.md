# P07 웨이브 시험장 실기 절차

상태: **실기 미실행**. 빌드 성공과 소스 식별자는 `p07-wave-lab.json`으로 확인한다. 자동 시험의 성공을 Quest Pro 관찰이나 최종 실제 맵 검증으로 확대하지 않는다.

실행 파일: `D:/Unity Project/Zombie Shoot VR/Zombie Shoot VR/Builds/Windows/WaveLab/WaveLab.exe`.
함께 있는 Data 폴더·DLL도 필요하다. 기존 EnemyLab과 InteractionLab은 별도로 보존한다.

## 조작과 화면

- 시작하면 준비 8초 뒤 1웨이브가 시작된다. 준비 중 이동·재장전은 가능하고 사격은 차단된다.
- **왼손 X / F6**: 전체 전투 일시정지·재개. **왼손 Y / F7**: 언제든 새 도전으로 재시작.
- 재시작 직후에는 왼손 그립을 놓았다 다시 잡는다. 누른 채 재시작한 그립을 새 잡기 입력으로 처리하지 않는다.
- 양손 앞부분 잡기와 오른손 트리거 사격, 왼손 탄창 탈거→버리기→왼쪽 허리 보급→삽입→앞부분 다시 잡기를 사용한다.
- 앞쪽 상태판에 HP, 실제 시작한 WAVE, KILLS, ROUNDS, ALIVE, PENDING, 준비 시간을 표시한다. 최종 오른팔 UI·메뉴·영구 기록은 P08에서 연결한다.
- 노란 원기둥은 생성 예고다. 약 1.5초 뒤에도 위치·거리·경로 조건이 유효해야 적이 나온다. 초록색 적은 근접, 보라색은 원거리이며 원거리는 3웨이브부터 등장한다.

## T08·T09: 체력과 웨이브

1. 처음 HP 100, 준비 중 WAVE 0, 준비 종료 후 WAVE 1을 확인한다.
2. 첫 웨이브의 근접 공격은 10 피해다. 가능한 경우 HP 70에서 마지막 적을 처치하여 90으로 한 번 회복하는지 본다. 다른 체력에서 클리어했다면 실제 전후 값을 기록한다. 회복은 100을 넘지 않아야 한다.
3. 여러 적에게 겹쳐 맞을 때 0.5초 보호 중 연속 피해가 들어가지 않는지 관찰한다. 정확한 시간 경계의 자동 시험과 실기 관찰을 구분한다.
4. ALIVE와 PENDING을 본다. 1웨이브는 총 6명, 동시에 최대 4명이다. 남은 적이 있으면 조기 클리어하지 않아야 한다. 전부 처치한 뒤 8초 준비에 들어간다.
5. 준비 중에는 직전 웨이브 번호를 유지하고, 다음 전투가 시작되어야 번호가 올라간다. 3웨이브에는 원거리 1명, 근접 9명이다.

## T12: 정지·사망·재도전

1. 이동·회전 중 X를 누른다. 스틱 이동·회전, 사격, 재장전 상호작용, 적 이동·애니메이션, 투사체, 생성 예고와 준비 시간이 정지해야 한다.
2. 정지 중 머리와 양손을 움직인다. 머리 보기와 총의 오른손 추적은 유지되어야 한다. 떨어지는 탄창도 정지하고, 재개하면 낙하를 이어가야 한다.
3. 정지 중 왼손을 앞부분에서 멀리 옮기거나 그립을 놓고 재개한다. 이전 양손 상태만으로 발사되어서는 안 된다. 탄창을 잡고 있었다면 실제 손 상태와 삽입 위치를 다시 확인해야 한다.
4. HP 0이 되면 Dead 상태에서 추가 공격·사격이 멈추는지 본다. 마지막 처치와 사망이 겹쳐도 회복으로 살아나서는 안 된다. 재현하지 못한 동시 사건은 미관찰로 기록한다.
5. 탄창을 일부 사용하거나 손에 든 상태·바닥에 버린 상태·정지 상태·사망 상태에서 Y로 재도전한다. 총 10회 확인한다. 매번 HP 100, ROUNDS 30, KILLS 0, WAVE 0, 준비 8초이며 이전 적·탄창·투사체가 남지 않아야 한다.

## T13: 실제 도달 번호

1. 5웨이브 클리어 후 준비 중에는 WAVE 5인지 확인한다.
2. 6웨이브 시작 후 사망하면 WAVE 6을 유지해야 한다. 이 시험장의 상태 표시 확인이며 영구 최고 기록 저장은 아직 포함하지 않는다.

회신 형식: `빌드/날짜; T08 체력 전→후·겹친 피격; T09 웨이브/생존/대기; T12 정지·손 재평가·재도전 성공 __/10; T13 준비/사망 번호; 실패 순서·양안 표시·조작 편안함`.

현재 시험장은 임시 도형과 임시 적 외형을 사용한다. 실제 방·강의실, 최종 UI, 72Hz 성능·30분 안정성은 별도 미완료 항목이다.
