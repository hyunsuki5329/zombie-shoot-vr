# P05 수동 재장전 실기 확인

준비일: 2026-09-23. 상태: **사용자 실기 결과 대기**. 자동 시험과 Windows 빌드는 통과했지만 아래 시험을 대신하지 않는다.

실행: `D:/Unity Project/Zombie Shoot VR/Zombie Shoot VR/Builds/Windows/InteractionLab/InteractionLab.exe`

이번 빌드는 왼손 그립으로 탄창을 교체할 수 있다. 임시 총 모델이며 왼쪽 허리에 보급 위치를 표시하는 큐브가 있다. 기존 Virtual Desktop 프로필을 유지해 조작을 확인한다. 성능 합격 판정은 별도의 고정 프로필 측정으로 진행한다.

## T06: 잔탄 교체와 빈 탄창 재장전 — 각각 10회

1. 왼손으로 총 앞부분을 잡고 사격한다. 잔탄이 남은 경우와 0발인 경우를 각각 시험한다.
2. 왼손 그립을 놓고 총 아래 탄창 가까이에서 다시 그립을 누른다. 탄창이 왼손으로 이동하고 잔탄은 0이 되어야 한다.
3. 그립을 놓아 탄창을 바닥에 버린다. 왼쪽 허리 표시 가까이에서 그립을 새로 눌러 새 탄창을 잡는다.
4. 그립을 유지하며 탄창을 총 삽입구에 방향을 맞춰 넣는다. 거리 12cm 이내·각도 35도 이내에서 결합하고 30발이 되어야 한다.
5. 그립을 놓았다가 총 앞부분에서 다시 잡는다. 그 뒤 오른손 트리거로 정상 사격되어야 한다.

## T07: 예외 입력 — 각 조건 10회

- 탈거한 탄창을 다시 집어 넣어도 결합하거나 탄약이 복구되지 않는다.
- 새 탄창을 놓쳐도 허리에서 새 그립 입력으로 다시 공급받을 수 있다.
- 방향을 크게 틀린 탄창은 결합하지 않고 올바르게 돌렸을 때 결합한다.
- 허리에서 그립을 계속 눌러도 여러 탄창이 연속 생성되지 않는다.
- 탄창을 든 손으로 앞부분을 잡아 사격할 수 없다. 삽입 후에도 앞부분을 별도로 다시 잡아야 한다.
- 버린 탄창은 바닥에서 떨어져 멈추고 약 12초 후 회수된다. 손에 든 탄창은 12초 이상 유지해도 사라지지 않는다.
