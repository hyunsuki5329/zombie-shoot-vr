# P10 전투 소리 실기 확인

대상: 이번 `Zombie Shoot VR/Builds/Windows/MenuLab/WaveLab.exe`. 아직 실제 청취 결과가 아니다. 음원은 자체 합성한 짧은 신호이며 자연스러운 좀비 녹음이나 최종 음량으로 주장하지 않는다.

1. 준비 8초가 끝나 실제 웨이브가 시작할 때 시작음이 한 번 들리는지 확인한다. X로 정지·재개해도 웨이브 시작음이 다시 나면 안 된다.
2. 실제 피해를 받으면 짧은 피격음이 난다. 피격 보호 0.5초 안에 무효 처리된 공격에서는 피격음이 추가로 나면 안 된다.
3. HP가 25 초과에서 25 이하(생존)로 내려갈 때 저체력 신호가 한 번 난다. 기존 팔 HUD의 붉은 글씨/느낌표도 확인한다. 낮은 HP를 유지하는 동안 매 프레임 반복되는 신호나 지속적인 붉은 전체 화면은 없어야 한다.
4. 적이 6m 안에서 접근할 때 낮은 접근음이 들리는지 확인한다. 간격은 최대 3초에 한 번이며 적의 위치에 따라 방향·크기가 달라져야 한다.
5. 근접/원거리 적이 노란 공격 준비 상태로 바뀔 때 각각 다른 준비음이 한 번 들리는지 확인한다. 준비음이 실제 공격/투사체보다 먼저 들려 피할 수 있어야 한다. 접근음이 준비음을 덮으면 안 된다.
6. 소리가 나는 중 X로 정지하고 사망/재도전을 반복한다. 정지·사망 시 기존 전투 소리가 중단되고 풀 재사용 뒤 소리가 중복 재생되지 않아야 한다. 치명 피해 프레임의 짧은 피격음도 사망 상태에서 중단한다.
7. 무기 소리·좌우 햅틱이 이전 절차대로 동작하는지 함께 확인한다. 머리/손 추적과 실제 청취를 자동 시험으로 대신하지 않는다.

반환 기록: 날짜 / 소스·빌드 식별자 / VD 설정 / 헤드셋 음량 / 단계별 결과 / 들리지 않거나 너무 큰 소리 / 방향·중복·지연 문제 / 소리만으로 공격 예고를 알아차렸는지.

현재 소리 통로는 `Audio/AudioMixer.mixer`의 Master다. 개인 피격/웨이브/저체력은 2D 소리, 무기와 적은 3D 소리다. 플레이어 전투 소리 3개, 무기 3개, 적당 2개의 AudioSource를 고정 재사용한다. 실제 CPU/GPU·오디오 비용과 장시간 안정성 측정은 별도다.
