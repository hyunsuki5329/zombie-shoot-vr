# P10 첫 조작 안내 실기 확인 (T19)

상태: 자동 시험과 별도로 실제 초보 사용자 관찰이 필요하다. 아직 실기 통과 기록이 아니다.

## 실행

- 시작 안내: `Zombie Shoot VR/Builds/Windows/BootstrapPreview/BootstrapPreview.exe`. 시작하면 Instructions가 나타난다. Back으로 맵 선택 화면에 돌아간다. 현재 실제 스캔 맵이 없어 Room/Classroom은 선택할 수 없다.
- 전투 연습: `Zombie Shoot VR/Builds/Windows/MenuLab/WaveLab.exe`. X로 정지한 후 Controls를 선택한다. 현재 안내는 영어이며 한국어 설명은 아래와 같다. 실제 안내만으로 이해 가능한지도 관찰한다.

## 게임 내 안내 내용

1. 왼쪽 스틱 이동, 오른쪽 스틱 회전.
2. 왼손 그립으로 앞부분을 잡고 오른손 트리거로 발사.
3. 재장전: 앞부분을 놓고 왼손 그립으로 탄창을 잡아 탈거한다.
4. 그립을 놓아 버린다. 남은 탄환은 폐기된다.
5. 왼쪽 허리에서 그립으로 새 30발 탄창을 꺼낸다.
6. 탄창을 삽입하고 앞부분을 다시 잡는다.
7. 오른팔에서 체력·웨이브·처치 수를 확인한다.
8. 왼손 X로 정지하고 포인터로 메뉴 버튼을 선택한다.

## 관찰 절차

사전 구두 설명 없이 게임 내 안내를 읽게 한다. Back으로 닫은 뒤 정지 상태가 유지되는지 확인하고 Resume으로 재개한다. 안내만으로 이동·회전·한 번 이상 양손 발사·수동 재장전·팔 HUD 확인·X 정지를 수행하는지 관찰한다. Controls로 안내를 다시 열 수 있어야 한다.

안내 화면에서 X를 누르면 정지 메뉴로 돌아가며 즉시 전투를 재개하면 안 된다. 머리와 손 추적은 유지되어야 한다. 글자 잘림·양안 가독성·버튼 선택·총/탄창 가림을 함께 확인한다.
