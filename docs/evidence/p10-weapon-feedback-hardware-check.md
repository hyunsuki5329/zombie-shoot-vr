# P10 무기 소리·진동 실기 절차

상태: 실제 Quest Pro에서 미검증. 자동 시험은 이벤트 발생·중복 방지·객체 수를 확인하며, 들리는 소리와 진동의 강도·지연은 확인하지 못한다.

대상: `Zombie Shoot VR/Builds/Windows/MenuLab/WaveLab.exe`의 이번 피드백 빌드. 소스와 파일 해시는 `p10-weapon-feedback.json`에 연결한다.

1. 양손으로 잡고 한 번 발사한다. 총성과 오른손의 짧은 진동이 한 번 나타나야 한다. 왼손을 놓거나 총구가 벽에 막히면 발사·총성·발사 진동이 없어야 한다.
2. 연사한다. 발사 간격에 맞춰 짧은 소리가 이어져야 하며 소리가 계속 쌓여 커지면 안 된다. 카메라 반동을 추가하지 않았다.
3. 탄창을 비운 채 트리거를 계속 누르면 빈 총 소리가 반복되지 않아야 한다. 트리거를 놓고 다시 누르면 짧은 빈 총 소리 한 번이 나야 한다.
4. 왼손으로 수동 재장전한다. 새 탄창 삽입 성공 시 삽입 소리와 왼손 진동이 한 번 나야 한다. 이미 삽입된 탄창을 누르거나 실패한 삽입에서 반복되면 안 된다.
5. 발사 직후 X로 정지한다. 소리는 멈추고 정지 중 발사 피드백이 없어야 한다. 재개 후에는 트리거를 놓고 다시 눌러야 발사된다.
6. 재도전을 10회 반복한다. 최초 자동 장착에는 삽입 소리가 나지 않아야 하며 이후 정상 발사·삽입에 중복 소리/진동이 생기면 안 된다.

반환 기록: 날짜 / 빌드 식별자 / VD 설정 / 헤드셋 음량 / 단계별 성공 여부 / 좌우 진동 위치 / 너무 강하거나 약한 정도 / 중복·지연·끊김 관찰.

현재 초기 후보는 음량 0.35, 발사 진동 0.25×35ms, 삽입 진동 0.20×55ms이다. 해당 숫자는 실기 측정 결과가 아니다. 음원은 직접 합성한 짧은 신호이며 현실 K2 녹음으로 주장하지 않는다. 피격·웨이브·적 접근/공격 준비·저체력 소리와 AudioMixer 구성은 후속 작업이다.
