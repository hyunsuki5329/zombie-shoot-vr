# 공간·가구 크기 조정

## 2026-10-16 공간과 가구 배율 분리

사용자 요청으로 원본 대비 폐가 공간2배(8.6×7m)·가구1.5배, 폐교 공간2배(28×12.6m)·책상/의자1.5배로 변경했다. 현재 배치에서 폐가 위치/벽/복도는0.8배, 가구 크기는0.6배이며 폐교 위치/벽/칠판은2배, 책상/의자는1.5배다. 가구 바닥 접점과 사용자 회전·옷장 축별 비율을 보존한다. 플레이어·총·적 크기와 점프 설정은 유지한다. 폐가 의자 옆의 독립 흰 막대10삼각형을 제거하고 실제 다리를 남겼다.

현재 저장 씬이 배치 기준이다. `AuthoredMapScaleSetup.Configure`는10월15일 저장 씬에서 이번 변경으로 이동하는 일회성 도구이며 마커가 있는 씬에서는 크기를 반복 적용하지 않는다. `UserLayoutSetup.Configure`는 현재 외형에서 충돌/NavMesh를 동기화한다. RoomHousePreview는 같은 NavMesh를 쓰므로 최신 Room 복사본으로 맞췄다. 초기 씬 생성 도구로 되돌리지 않는다. 의자 수정은 로컬 Granny 생성 메시에도 반영했으며 원본 ZIP에서 다시 생성하면 이번 도구의 정리 단계를 적용해야 한다.

검증 로그: `tmp/scale-20261016/`. Room7/7·Classroom8/8 생성점 연결, 반복 실행 시 외형/앵커 위치·회전·크기 불변, 의자 및 두 맵 렌더 확인. 독립 리뷰에서 복도 벽 분류 누락을 발견해 수정하고 벽 높이 검사로 보강했다. 사용자 VR 인수는 아직 미실행이다.
