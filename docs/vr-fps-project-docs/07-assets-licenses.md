# 무료 에셋과 출처 관리

현재 실제 포함 자산은 [2026-09-29 출처 조사와 원문 고지](../asset-provenance.md)를 따른다. 아래 외부 모델 후보를 실제 채택한 것으로 해석하지 않는다.

## 실제 임시 자산 기록 — 2026-09-22

P04-b의 `Assets/VRFPS/Prefabs/Weapons/K2.prefab` 외형과 `Assets/VRFPS/Materials/`의 단색 재질은 프로젝트에서 Unity 기본 도형으로 자체 작성했다. 외부 K2 모델을 다운로드하거나 채택한 것이 아니며 최종 K2 실루엣·분리 탄창 요건의 완료 증빙으로 사용하지 않는다. 작성 경로는 `Assets/VRFPS/Editor/WeaponLabSetup.cs`이고, 조작 검증 후 아래 후보의 사용 조건을 확인하여 교체할 예정이다.

2026-09-18 · 아래는 채택 후보 목록이다. 아직 다운로드·임포트·VR 호환 검증을 마친 에셋은 없다. 가격과 사용 조건은 실제 확보 시 다시 확인한다.

## 1 확보 순서

먼저 단순한 임시 모델로 P04~P08의 조작을 완성하고 검증된 실제 모델로 교체한다. K2는 실루엣·오른손 위치·왼손 앞부분·분리 탄창이 중요하고, 좀비는 Humanoid 리깅과 이동·공격·사망 동작 연결이 중요하다. 시각 효과는 성능 검증 후 소수만 추가한다.

| 용도 | 무료 후보와 근거 | 채택 전 검사 | 대안 |
|---|---|---|---|
| K2 | [GAMGO DAEWOO K2](https://sketchfab.com/3d-models/daewoo-k2-258d30e1f3e04c13a60abd916425b0c2), 무료 다운로드 후보 | 실제 라이선스, 파일 형식, 분리 탄창, 피벗·스케일·텍스처 | 동일 조건의 다른 무료 K2 또는 직접 단순 모델 제작 |

| 총구·피격·침 효과 | [War FX](https://assetstore.unity.com/packages/vfx/particles/war-fx-5669), 무료 표시와 다수 사용자 평가 | URP 재질, 두 눈 렌더링, 과도한 파티클·투명도·빛 | 기본 Particle System으로 작은 효과 직접 제작 |

| 총성·발걸음·피격 | 직접 녹음 또는 출처가 명확한 무료 효과음 | 라이선스·음량·루프 이음새, 최종 음원별 출처 | 직접 제작한 짧은 기본 소리 |

War FX는 사전 확인 시 300개 이상의 평가가 있는 후보였지만 다른 후보의 이용자 수와 개별 동작 인기는 확인하지 않았다. ‘모두 인기 에셋’이라고 표시하지 않는다. 전체 유료 번들과 무료 Standard를 혼동하지 않는다. [Quaternius 제작자 페이지](https://quaternius.com/packs/universalanimationlibrary.html)

## 2 캐릭터 동작 목록

근접형은 Idle, Walk 또는 느린 Run, Melee Attack, Hit Reaction, Death가 필요하다. 원거리형은 같은 이동·피격·사망을 공유하고 별도의 준비 자세와 발사 동작을 사용한다. 산성 침에 정확히 맞는 무료 클립이 없으면 상체 공격 클립의 준비·복귀 구간을 조정하고 발사 지점을 이벤트로 연결한다.

플레이어 재장전은 실제 왼손 입력으로 진행한다. Mixamo 재장전 애니메이션이 자동으로 탄창을 옮겨 사용자의 조작을 대신하게 하지 않는다. 손가락 잡기 자세만 클립 또는 단순 포즈로 보완한다.

애니메이션 리타깃 후 발 미끄러짐·크기·팔 관통을 확인한다. NavMeshAgent가 이동을 결정하므로 기본 이동 클립은 in-place를 사용한다. 공격 피해는 매 프레임 접촉이 아니라 지정된 타격 순간 1회만 발생한다.

## 4 소스와 에셋 배포

게임 빌드 안에 사용하는 권한과 원본 모델·애니메이션 파일을 공개 배포하는 권한은 별도로 확인한다. 과제 소스 제출도 해당 조건에 맞춰 준비한다. 외부 에셋 원본을 공개 저장소에 일괄 업로드하지 않는다. 허용 범위가 불명확한 에셋은 제출 전에 대체하거나 재다운로드 절차를 제공한다.

직접 촬영한 공간, 자체 코드, 외부 에셋, 오픈소스 렌더러를 출처표에서 구분한다. 렌더러와 그 안의 예제 스캔 데이터도 같은 라이선스라고 가정하지 않는다. Mixamo 활용 범위는 [Adobe 공식 FAQ](https://helpx.adobe.com/creative-cloud/faq/mixamo-faq.html), Asset Store 자산은 실제 상품 페이지와 포함된 라이선스를 확인한다.
