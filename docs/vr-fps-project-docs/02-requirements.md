# 요구사항 명세 · PRD

2026-10-20 추가 설계: **현실 공간 GS 감상 → 큰 바이러스 사격 → 암전 → 테마 맵 등장 → 전투 시작**을 P13으로 추가한다. 상세 동작은 [11 설계](11-gs-comparison-intro.md), 작업 순서는 [12 계획](12-gs-comparison-plan.md)을 따른다. 현재 문서화 단계이며 구현·새 기기 검증은 미완료다. 1차 대상은 Room, Classroom GS는 별도 자료 확보 후 후속 적용한다.

2026-10-16 최신 기준: 폐가 공간2배·가구1.5배, 폐교 공간2배·책상/의자1.5배. 아래 이전 크기 설명보다 이 결정이 우선한다. [상세 변경](../map-scale-20261016.md)

2026-10-12 범위 갱신: **내 방(`room`) → 폐가(`AbandonedHouse`), 실제 강의실(`classroom`) → 폐교(`AbandonedSchool`)**로 고정한다. 두 공간의 스캔·실측을 수동 구조 데이터로 정리하고, 그 위치·크기에 맞는 테마 프리팹으로 재구성한다. 다른 사용자의 공간 지원과 같은 맵의 테마 선택 기능은 범위에 포함하지 않는다. 세부 계약은 [Method A 가이드](../VRShoot_Method_A_Codex_Guide.reviewed.md)를 따른다. 이 갱신은 문서 변경이며 테마 구현 완료나 Goal 재개를 뜻하지 않는다.

원안 1.0 · 2026-09-18 / GS 확장 1.2 · 2026-10-20. 이 문서는 기능 요구사항의 기준이다. 과거 날짜의 갱신보다 최신 R표와 P13 설계를 우선한다.

### 사용자 지정 흐름과 설계 기본값

사용자가 정한 것은 GS 현실 공간, 총과 공중의 큰 바이러스, 명중 후 암전·밝아짐·테마 전투 순서와 모델이다. 첫 명중1회, 페이드1.2초씩, 검정 최소0.25초, 직경0.8m/거리2m, 재도전 시 도입부 생략, Room 우선 적용은 [11](11-gs-comparison-intro.md)의 설계 기본안이다. 실기 결과로 조정할 수 있으며 이미 사용자 실기 승인을 받은 값으로 표시하지 않는다.

모든 상태에서 머리와 컨트롤러 추적은 유지한다. 일시정지에서 실제 손이 움직였다면 재개 시 총 앞부분 접촉과 탄창 위치를 다시 평가한다. 정지 직전의 양손 상태를 그대로 믿어 발사를 허용하지 않는다.

## 용어

- 도달 웨이브 `ReachedWave`: 실제 전투를 시작한 최대 번호. 도전 시작 전 내부값은 0, 화면은 ‘준비 중’.
- 클리어 웨이브 `ClearedWave`: 적 할당량의 처리가 끝난 번호. 회복·진행에 사용하며 결과 순위와 구별한다.
- 처치 `Kills`: 플레이어 피해로 사망 확정된 적만 한 번 증가. 막힌 적의 재배치나 시스템 회수는 처치가 아니다.
- 대기 적 `Pending`: 할당량 중 아직 생성에 성공하지 않은 수. 생성 위치가 없어 실패하면 줄이지 않는다.
- 앞부분 잡기: 왼손의 총 보조 손잡이 잡기. 오른손을 떼는 단계가 아니다.

## 범위의 경계

허용하는 단순화는 스캔을 수동 해석한 구조와 정적인 테마 프리팹 외형, 수동 충돌 구조, 미리 정한 생성점, 컨트롤러를 기준으로 추정하는 오른팔 UI, 단순한 적 2종과 무료 동작이다. 실측 팔꿈치 추적, 스캔 가구 물리 이동, 복잡한 탄도·약실·노리쇠 시뮬레이션은 요구하지 않는다.

수업 제출에 필요한 결과를 만드는 것이 목표이며 NeRF·GS 알고리즘을 처음부터 구현하지 않는다. 기존 GS 생성 도구·렌더러를 이용하는 P13 비교 도입부는 추가 범위에 포함한다. GS 내부 전투와 임의 사용자 공간 지원은 제외한다. 강의의 앱 사용 조건은 최신 공지로 확인한다. 계정·업로드·온라인 저장·멀티플레이는 범위 밖이다.
