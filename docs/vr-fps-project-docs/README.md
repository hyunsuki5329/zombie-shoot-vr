# 현실 공간 기반 VR 좀비 FPS 프로젝트 문서

2026-10-20 추가 설계: **현실 공간 GS 감상 → 큰 바이러스 사격 → 암전 → 테마 맵 등장 → 전투 시작**을 P13으로 추가한다. 상세 동작은 [11 설계](11-gs-comparison-intro.md), 작업 순서는 [12 계획](12-gs-comparison-plan.md)을 따른다. 현재 문서화 단계이며 구현·새 기기 검증은 미완료다. 1차 대상은 Room, Classroom GS는 별도 자료 확보 후 후속 적용한다.

현재 확장 문서는1.2(2026-10-20)이며 기존 PDF·ZIP은1.1 당시 보관본이다. 이번 변경에서 PDF/ZIP·발표자료를 다시 생성하지 않았다.

현재 맵 범위: **내 방 폐가 / 실제 강의실 폐교**. [고정 테마와 구조 제작 기준](../VRShoot_Method_A_Codex_Guide.reviewed.md). 기존 테마 게임은 사용자 인수를 받았고 새 GS 도입부는 설계 단계다. 문서 갱신 자체가 Goal 재개는 아니다.

작성일 2026-09-18 · 갱신일 2026-09-20 · 문서 묶음 버전 1.1 · 개인 학기 프로젝트

아이폰으로 촬영한 내 방과 강의실을 Unity PC VR 전투 공간으로 제작하는 프로젝트의 계획과 구현 기준이다. Quest Pro와 Virtual Desktop으로 플레이하며 K2 양손 사격, 왼손 수동 재장전, 근접·원거리 좀비, 무한 웨이브 생존을 구현한다.

먼저 **01 개발 계획서**로 전체 순서와 일정을 읽고, 실제 개발할 때 **진행 기록의 미완료 단위**에서 이어 간다. 새 P13은12 계획을 따른다. 문서는 작성된 상태이며 게임 구현, 에셋 임포트, 성능 측정이 완료되었다는 뜻은 아니다.

## 문서 사용 규칙

사용자의 최신 결정이 우선한다. 이번 묶음에서 기능의 기준은 02, 숫자의 기준은 06과 JSON, 구현 인터페이스의 기준은 03이다. 01과 PDF 계획서는 전체 실행 방향을 요약한다. 변경 시 관련 테스트와 일정도 함께 수정한다.

기존 압축 파일은1.1 보관본이며 현재1.2 확장은 Git의 Markdown 문서로 읽는다. 이전 기획 기준안과 가져온 1.0 문서는 `docs/shared-chat-2026-09-18/outputs/`에 원본 상태로 보관했다. 1.1에서는 설치된 XRI 3.5.1과 기존 VR 템플릿을 기준으로 환경·구현 계획을 갱신하고 방 촬영 방법을 구체화했다. 당시1.1에서는 기능 요구사항과 게임 밸런스를 변경하지 않았다. 현재1.2는 R21~R28/P13과 도입부 초기값을 추가한다.

**확정**은 사용자 결정, **초기값**은 테스트 후 조정할 제안, **검증 조건**은 실제 실행 결과로 결정할 사항이다. 진행 체크박스는 모두 미완료에서 시작한다. 측정값과 실제 채택 에셋은 실행 후 기록하며 예상치를 실측치로 표시하지 않는다.

## 초기 프로젝트 시작 순서 (역사적 계획)

현재는 기존 개발을 재시작하지 않고 진행 기록의 완료 상태에서 P13-a를 준비한다.

1. 최신 수업 공지에서 제출일과 외부 스캔 앱 사용 조건을 확인하고 10의 확인표에 기록한다.
2. 새 프로젝트 또는 사용자가 지정한 프로젝트를 P01의 환경으로 열고 Quest Pro에서 빈 공간을 실행한다.
3. 방 전체를 만들기 전에 작은 구역을 촬영하여 P02의 표시·가림·성능 검증을 끝낸다.
4. P03~P08로 작은 시험 공간 안에서 사격부터 사망·기록까지 한 번의 플레이를 완성한다.

개발 시간은 주당 15시간, 총 160시간을 계획 가정으로 사용한다. 실제 확보 시간과 Unity 경험에 따라 일정은 조정한다. 핵심 요구사항을 임의로 삭제하는 일정 단축은 하지 않는다.
